# Adding a language (i18n)

XIT Games runs one engine for every game. Music and sound effects are
**universal** — they're never translated. Only two things are language-specific:

1. **On-screen copy** — buttons, labels, flash banners (the `ThemeCopy` strings).
2. **Voice lines** — the spoken win/loss barks (`voice-win-*`, `voice-crash-*`).

English is the built-in base: every theme ships English copy + English voice, so
a translation only has to fill in what it wants — anything missing falls back to
English automatically.

## How a language is chosen

Client-side, in order: `?lang=<code>` in the URL → the visitor's saved choice
(localStorage) → the browser language → English. An explicit `?lang=` is
remembered. So you can preview Dutch with `…/liftoffx?lang=nl`.

To switch in code, use the hook:

```ts
import { useLocale } from '@/hooks/useTheme';
const { locale, setLocale, locales } = useLocale();
```

## Add a new language

1. Add its code to `LOCALES` and a display name to `LOCALE_NAMES` in
   `src/i18n/index.ts`.
2. Create `src/i18n/translations/<code>.ts` exporting a
   `Record<themeKey, ThemeLocale>` (copy `nl.ts` as a template). Translate as
   many keys as you like; leave the rest out to keep English.
3. Register it in the `TRANSLATIONS` map in `src/i18n/index.ts`.

That's it — the copy is live. No engine changes.

## Add localized voice lines (optional)

Voice clips default to English. To give a language its own voice for a game:

1. Drop the clips in `public/themes/<game>/audio/<code>/`, e.g.
   `voice-win-1.mp3 … voice-win-5.mp3`, `voice-crash-1.mp3 … voice-crash-5.mp3`.
2. In that language's translation entry for the game, point at them:

   ```ts
   liftoffx: {
     copy: { /* … */ },
     voiceCrash: [1,2,3,4,5].map(n => `/themes/liftoffx/audio/nl/voice-crash-${n}.mp3`),
     voiceWin:   [1,2,3,4,5].map(n => `/themes/liftoffx/audio/nl/voice-win-${n}.mp3`),
   },
   ```

Leave `voiceCrash`/`voiceWin` out to keep the English voice while still
translating the on-screen text — a common, cost-effective setup (the cinematic
English barks stay; the UI is localized). See `docs/audio/<game>.md` for the
voice-line scripts to translate + record.
